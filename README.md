# 🌽 Cuscuz Delivery

**Aplicativo de delivery de cuscuz e acompanhamentos, desenvolvido com React Native e Expo.**

## 📌 Sobre o projeto

O **Cuscuz Delivery** é um aplicativo mobile desenvolvido com o objetivo de facilitar a compra e a entrega de cuscuz, oferecendo aos clientes uma experiência simples, prática e intuitiva.

A proposta é permitir que o usuário explore os produtos disponíveis, escolha seus itens, monte seu carrinho e informe os dados necessários para a realização do pedido.

O projeto também busca aplicar, na prática, os conhecimentos adquiridos em desenvolvimento de software, programação mobile, organização de componentes e gerenciamento de estados.

## 🎯 Objetivos

- Desenvolver uma aplicação mobile utilizando tecnologias modernas.
- Facilitar o processo de compra de cuscuz por meio de um aplicativo.
- Proporcionar uma interface intuitiva e agradável.
- Aplicar conceitos de programação, componentização e navegação.
- Desenvolver conhecimentos práticos em React Native e TypeScript.

## 🚀 Funcionalidades

Atualmente, o projeto conta com as seguintes funcionalidades:

- **Tela inicial:** apresentação dos produtos disponíveis e suas categorias.
- **Catálogo de produtos:** exibição de produtos com imagens e informações.
- **Categorias:** organização dos produtos para facilitar a navegação.
- **Carrinho de compras:** gerenciamento dos produtos selecionados.
- **Checkout:** formulário para preenchimento dos dados do cliente.
- **Endereço de entrega:** campos para endereço, bairro e complemento.
- **Formas de pagamento:** seleção entre Pix, cartão e dinheiro.
- **Opção de troco:** possibilidade de informar se precisa de troco e o valor desejado.
- **Navegação:** movimentação entre as telas do aplicativo.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Finalidade |
|---|---|
| React Native | Desenvolvimento da interface mobile |
| Expo | Ambiente e ferramentas para desenvolvimento |
| Expo Router | Navegação entre as telas |
| TypeScript | Tipagem e organização do código |
| NativeWind | Estilização utilizando classes semelhantes ao Tailwind CSS |
| React Hooks | Gerenciamento de estados e comportamentos |
| Context API | Compartilhamento de estados entre componentes |
| Feather Icons | Utilização de ícones na interface |
| Git e GitHub | Versionamento e hospedagem do código |

## ⚙️ Como executar o projeto

### Pré-requisitos

Antes de começar, é necessário ter instalado:

- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/)
- Expo Go no dispositivo móvel ou um emulador Android/iOS.

### 1. Clone o repositório

```bash
git clone https://github.com/kawe-07/cuscuz-delivery.git
```

### 2. Entre na pasta do projeto

```bash
cd cuscuz-delivery
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o projeto

```bash
npx expo start
```

Após iniciar, escaneie o QR Code com o Expo Go para visualizar o aplicativo no dispositivo móvel.
